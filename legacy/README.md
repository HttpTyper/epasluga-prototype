# Е-Паслуга — прототип (срез 1)

Статический прототип трёх экранов: главная, каталог, карточка услуги.

Цвета и левое меню как на текущем портале. Кликабельны только главная («Мой профиль»), «Все услуги» и карточки услуг.

## Запуск

В папке проекта:

```bash
python3 -m http.server 4173
```

Откройте http://127.0.0.1:4173/

## Что уже есть

- Жизненные ситуации и быстрые действия на главной
- Человеческие названия + официальная формулировка и код
- Бейдж «Без ID-карты» у справочных услуг, «ЭЦП — нужна подпись» с пояснением
- Поиск с синонимами (доходы, паспорт, авто, пенсия…)
- Карточка: блок «Что вы получите», организация и УНП
- Универсальная форма: живая валидация, автосохранение черновика, демо-отправка

Описания сроков и стоимости — заглушки до ваших регламентов.
